# Eduford - Modern University Website

Eduford is a premium, fully responsive university website designed to provide a seamless user experience for students, faculty, and visitors. The project showcases modern web development practices, focusing on performance, aesthetics, and interactive elements.

## 🚀 Key Features

- **Responsive Design:** Optimized for all screen sizes (Mobile, Tablet, Desktop).
- **Interactive Animations:** Powered by **GSAP (GreenSock Animation Platform)** and **ScrollTrigger** for a modern, engaging feel.
- **Multi-page Architecture:** Dedicated pages for Home, About, Courses, Blog, and Contact.
- **Dynamic Headers:** Transparent-to-Solid sticky header transitions.
- **Advanced CSS:** Use of Hover effects, flexbox/grid layouts, and overlay layers for depth.
- **Contact Integration:** Functional-styled contact forms and interactive maps.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Animations:** GSAP 3.x, ScrollTrigger
- **Icons:** FontAwesome 6+
- **Fonts:** Google Fonts (Poppins family)

## 🎥 Animation Highlights (GSAP)

One of the project's standout features is its animation system:

1.  **Text Splitting:** Custom JS logic splits titles into individual characters to create a "staggered" entry animation.
2.  **ScrollTrigger Integration:**
    *   **Courses Section:** Blocks fly in from the Y-axis as you scroll.
    *   **Campus Section:** Images gently fade and scale on scroll.
    *   **Testimonials:** Smooth horizontal entry for user reviews.
    *   **CTA:** Dynamic "call to action" entry to catch users' attention.

## 🌟 How to Run

1.  Clone the repository or download the files.
2.  Open `index.html` in any modern web browser.
3.  Enjoy the animations as you scroll through the pages!
